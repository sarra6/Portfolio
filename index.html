DocuMind
v1.0
DocuMind is a full-stack RAG application — users upload documents through a Next.js frontend, a Spring Boot backend extracts and chunks the text, generates vector embeddings using a locally-run AI model via Ollama, and stores everything in a PostgreSQL database with the pgvector extension for semantic search. When a user asks a question, the system retrieves the most relevant document chunks using vector similarity search and sends them to an LLM to generate a grounded, cited answer — all secured with JWT-based authentication, and the whole database layer containerized with Docker for reproducibility.
Comment ça marche

Lorsqu'un utilisateur pose une question, le système récupère les chunks de documents les plus pertinents via recherche par similarité vectorielle et les envoie à un LLM pour générer une réponse fondée et citée — le tout sécurisé par authentification JWT, avec la couche base de données containerisée via Docker pour la reproductibilité.

Next.js Spring Boot PostgreSQL pgvector Ollama Docker
