Projets

DocuMind
v1.0
Application full-stack de type RAG (Retrieval-Augmented Generation) permettant d'interroger des documents en langage naturel. L'utilisateur charge ses fichiers via une interface Next.js, le backend Spring Boot les découpe et génère des embeddings vectoriels grâce à un modèle IA exécuté localement via Ollama. Ces vecteurs sont stockés dans une base PostgreSQL avec l'extension pgvector pour permettre une recherche par similarité sémantique. Lorsqu'un utilisateur pose une question, le système retrouve les passages les plus pertinents et génère une réponse sourcée grâce à un LLM. L'ensemble est sécurisé par authentification JWT et conteneurisé avec Docker pour garantir la reproductibilité.
Comment ça marche

Lorsqu'un utilisateur pose une question, le système récupère les chunks de documents les plus pertinents via recherche par similarité vectorielle et les envoie à un LLM pour générer une réponse fondée et citée — le tout sécurisé par authentification JWT, avec la couche base de données containerisée via Docker pour la reproductibilité.

GUARDIA

ShopFlow
v1.0
Plateforme e-commerce full-stack couvrant l'ensemble du parcours d'achat, du catalogue jusqu'au paiement. L'authentification des utilisateurs est sécurisée grâce à JWT, garantissant la protection des comptes et des données sensibles. Comment ça marche

L'utilisateur s'authentifie via JWT, parcourt le catalogue, ajoute des articles au panier et passe commande. Le back-office permet aux administrateurs de gérer les produits, les stocks et le suivi des commandes.

HealthGuide
v1.0
Application web de suivi médical pensée pour simplifier la gestion des documents de santé au quotidien. Elle intègre une technologie d'OCR (reconnaissance de texte) permettant d'extraire automatiquement les informations d'ordonnances et de documents médicaux scannés. Un chatbot intelligent, basé sur l'API Google Gemini, accompagne l'utilisateur pour répondre à ses questions et l'aider à interpréter ses documents. L'interface, développée en React, offre une expérience fluide et accessible. Le backend Express.js orchestre la communication entre l'OCR, le chatbot et le stockage des données utilisateur.
Comment ça marche

L'utilisateur télécharge une ordonnance ou une analyse médicale scannée. Le moteur OCR extrait le texte du document, puis le chatbot Gemini interprète les informations, répond aux questions du patient et synthétise les points essentiels pour faciliter la compréhension et le suivi médical.
